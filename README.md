# 实时字幕增强 · WinUI 3

复用 Windows 11 原生实时字幕识别，提供可选字的字幕浮窗与完整历史。应用的主窗口、历史窗口、样式窗口、菜单、滚动条和确认对话框全部使用 WinUI 3。字幕只在本机处理和保存。

## 运行

双击根目录的 `启动字幕增强.cmd`，或运行：

```text
artifacts/LiveCaptions-WinUI3/LiveCaptions.Enhanced.exe
```

分发包为 `artifacts/LiveCaptions-WinUI3-win-x64.zip`。请完整解压后运行，不要单独移动 EXE。目录版自带 .NET 8 和 Windows App SDK 运行库，无需安装 MSIX 或另装运行库。需要 Windows 11 x64，且系统实时字幕已完成初始化与语言安装。

旧 WPF 发布目录保留供回退，根目录启动入口使用新的 WinUI 3 发布目录。迁移前的源码、脚本和文档备份位于 `artifacts/migration-backup/before-winui3.zip`。

## 字幕浮窗

- 默认置顶，右侧为设置、历史、关闭图标，提供悬停提示和辅助功能名称。
- 文字区域（包括行间和行尾空白）保留拖选与复制，重新框选时清除旧选区，始终以当前按下的字符位置为起点。框选期间字幕继续实时更新并跟随最新一行，选区随识别修正与旧行移除重新定位；鼠标不动时，字幕滚动不会自动扩展选区。点击外侧空白取消文字选中；按住空白移动鼠标立即拖动窗口，无需等待，松开即停止。菜单展开时暂停窗口拖动，菜单文字和控件只响应自身操作。四边与四角支持缩放，主窗口禁止最大化。
- 最小高度按当前字号保留两行完整字幕。窗口变化时只显示完整行，实时区隐藏滚动条并跟随最新一行。需要查看旧字幕时打开历史窗口。
- 字幕采集在独立后台进程中运行，连接后每次读取结束约 60ms 再采样；变化立即发送，未变化时每 2 秒发送心跳。缓存有效的窗口和正文控件，避免周期性重扫 UI Automation 树。无响应超过 8 秒时自动重连。采样间隔不包含系统识别和 UI Automation 调用本身的耗时。
- 实时文字使用异步排版，仅在文字、字号或视口变化时更新末行位置；透明度滑块不重新排版文字。窗口拖动由空白按压及指针移动控制，使用屏幕物理坐标计算位移并跳过重复位置，避免快速拖动时相对坐标反馈造成跳动。WinUI 输入区域保留四边缩放；字幕外框由 XAML 绘制，禁用系统非客户区外框绘制并在主题、合成或 DPI 变化后恢复该策略，避免跨屏后灰色粗框覆盖客户区。

## 设置

“识别语言”只显示已安装语言，标记当前语言，点击即可切换。读取或切换期间可能短暂停止采集；错误菜单提供重试。初始化、下载语言包和麦克风设置仍由 Windows 提供。

“字幕样式”分为“文字”和“背景”两个页面，窗口固定大小，无页面滚动条、预览和说明文字；修改立即应用到字幕浮窗并自动保存：

- “文字”：字体、预设或自定义字号、文字效果、文字颜色。
- “背景”：背景颜色、背景透明度。

- 六类字体；小 16、中 22、大 28、特大 36 或 12–96 自定义字号。
- 无、凸起、凹陷、统一描边和投影五种文字效果，由 WinUI 文字图层实现。
- 文字与背景分别支持预设色、调色板或 `#RRGGBB` 输入；输入后按 Enter 或移开焦点应用。
- 背景透明度通过 DWM 逐像素合成独立于文字与按钮，0% 完全透出后方窗口，100% 不透明；透明空白仍可用于拖动。
- 配置路径沿用 `%LOCALAPPDATA%\LiveCaptions.Enhanced\caption-style.json`，兼容旧版数据。

“显示原生字幕”控制系统字幕窗口的可见性。应用在启动原生进程后立即挂接窗口监听，以全透明、鼠标穿透、不激活及最小化方式遮蔽窗口；采集连接中断或窗口重建期间继续维护隐藏。语言切换与持续隐藏共享同一套窗口状态。

首次初始化时可勾选“显示原生字幕”，完成设置后取消勾选。建议将原生字幕位置设为“屏幕上叠加”；顶部/底部停靠可能仍占用系统工作区，应用不修改该系统设置。

正常退出时先完成历史保存，再关闭本会话中的原生实时字幕并释放隐藏状态。强制终止或崩溃不保证联动关闭，可手动关闭后重新打开系统实时字幕。

## 历史

- 历史是独立 WinUI 窗口，按段落虚拟化显示，可以选取段内文字、滚动阅读；长段落分块排版。只在内容变化时更新相应段落，滚动和选字期间暂缓刷新，阅读旧记录时追加字幕不拉走滚动位置。
- “复制”复制当前全部历史，包括新到达的文字，不受选区影响。
- “导出”通过系统文件选择器保存 UTF-8 Markdown，按会话时间整理并转义字幕中的 Markdown/HTML 字符。
- 垃圾桶按钮弹出 WinUI 确认对话框，默认取消。确认后清空本机保存的历史及当前会话历史，无法撤销；需要保留内容时请先导出。
- 清空等待正在进行的保存完成；不删除手动导出的文件或样式设置。实时字幕继续显示，旧缓冲不回填，只记录后续新文字。失败时提供错误与重试机会。
- 每 5 秒自动保存至 `%LOCALAPPDATA%\LiveCaptions.Enhanced\History`，退出前再保存一次。意外退出可能损失最近约 5 秒的内容。旧版历史格式继续兼容。

## 开发与验证

需要 .NET 8 SDK、Windows SDK 与 NuGet 还原能力。界面采用 Microsoft.WindowsAppSDK.WinUI 1.8.260803003；构建目标为 net8.0-windows10.0.19041.0 / win-x64，识别功能要求 Windows 11。

```powershell
dotnet build LiveCaptions.sln -c Release
powershell -NoProfile -File scripts/Verify.ps1
powershell -NoProfile -File scripts/Publish.ps1
```

- `LiveCaptions.Core` 负责字幕合并、清空边界和 Markdown 导出。
- `LiveCaptions.Desktop` 的 UI 全部基于 Microsoft.UI.Xaml，未启用 UseWPF，不使用 WPF 窗口、控件或模板。原生采集服务仍使用 .NET UI Automation，因此保留 Windows Desktop 框架引用；发布目录一并携带所需运行库。
- `--worker`、`--language-settings`、`--diagnose <路径>` 在进入 WinUI 前分流，不创建应用窗口。诊断文件可能含当前字幕，仅按需保存。
- `--self-test <报告路径>` 使用报告旁全新的 `winui-test-GUID` 目录。测试在任何写入或清空前强制检查目录，不使用用户历史，也不会启动或关闭系统字幕进程。
- `scripts/Test-WinUI.ps1` 为自测启动器，处理打包终端传递 MSIX 身份导致的资源查找冲突。实际用户从资源管理器运行无需此脚本。
- 自动报告：`artifacts/winui-test.json`；真实 WinUI 渲染截图：`artifacts/winui-caption.png`、`artifacts/winui-history.png`、`artifacts/winui-style.png`。
- 回归覆盖实时选区、三窗口、样式控件、菜单、整行布局、末行跟随、历史保存/重读/清空，以及仅属于测试进程的 HWND 遮蔽、嵌套租约、新窗口和恢复。透明度用自建不透明底板上的实际桌面合成像素验证，拖拽/缩放检查实际输入子窗口；另覆盖持续字幕更新与 3000 段历史的虚拟化及阅读位置保持。
- 自动检查使用模拟字幕和测试 HWND，不代替真实音频识别、系统语言切换、多显示器、HDR、连续交互缩放或长期运行验收。旧 WPF 的历史报告不作为新界面的验证结果。

原生控件没有稳定的逐句完成标记，历史按连续快照合并。极端修正或两次采样之间整段文字消失时仍存在歧义；尚未保存且已从系统控件消失的文字无法恢复。应用启动时原生控件保留的文字可能被一起采集。
